# WuWa_Hekili (鸣潮连招助手) 🎮

**WuWa_Hekili** 是一款受《魔兽世界》知名插件 Hekili 启发，专为《鸣潮》开发的战斗连招辅助工具。它通过在屏幕上叠加透明的“技能流”图标，帮助玩家肌肉记忆复杂的输出轴（Rotation），提升实战 DPS。

**⚠️ 安全声明：本工具仅通过手柄/键盘信号监听实现逻辑跳转，不读取、不修改游戏内存数据，属于“绿色辅助”。但请注意，任何外部覆盖层工具在反作弊系统下均存在理论上的误封风险，请玩家自行承担后果。**

## ✨ 核心特性
- **极致视觉体验**：专门针对 Windows 11 深度优化的无边框、无阴影悬浮窗，完美融入游戏画面。
- **勋章式 UI 设计**：左上角对齐的角色标识卡片，配合动态缩放与古铜金（#cab286）配色，呈现大作级 UI 质感。
- **灵活的别名系统**：不再硬编码角色位置！支持自定义别名（如 "1", "2", "3" 或角色名），一键切换队伍配置。
- **可视化剧本上传**：内置 `routine_uploader.py` 辅助工具，支持拖拽式流程编辑与预览，告别手动改 JSON 的痛苦。
- **智能资源管理**： 
  - 多级降级查找：优先查找角色专属动作图，无素材时自动降级使用通用武器图。 
  - 模糊匹配：支持 normal, enhanced, forte, heavy 等关键词自动匹配文件名。
- **深度硬件监听**： 
  - 支持键盘、鼠标及 Xbox 手柄的底层硬件级监听（需管理员权限）。
  - 时效性：基于 QTimer 的心跳检查，确保操作反馈与游戏逻辑同步。

## 🛠️ 安装与运行

### 第一步：环境准备
1. 请确保安装了 **Python 3.10+**。
2. 克隆本项目：`git clone https://github.com/Herselfta/WuWa-Hekili.git`

### 第二步：安装依赖
在项目根目录下运行：
```bash
pip install -r requirement.txt
```

### 第三步：管理员启动 (关键)
为了保证钩子在游戏前台时有效，**必须以管理员身份运行**：
```powershell
# 在管理员终端中执行
python main.py
```

## 📝 编写你的战斗剧本
1. 运行 `python tools/routine_uploader.py` (或使用项目内置的上传工具)。
2. 定义各个动作的 `type`, `desc` 和 `variant`。
3. 在 `config.json` 中配置你的 `team` 别名，确保与剧本中的角色标识对应。
